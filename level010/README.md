# Level 010 - Functions (No Arguments)

## Description
This level adds function definition and function calls without arguments.

## Build
```bash
make
```

## Run
```bash
./calc
```

## Syntax
```
def foo() {
    x = 5;
    x + 1;
}

foo();
```

## Examples
```
def greet() {
    x = 10;
    x;
}

greet();
```

## Features
- Function definition: `def name() { stmts }`
- Function call: `name();`
- Functions return values
- All Level 009 features

## Clean
```bash
make clean
```
